# hookme for Dart

- [app/](app/README.md): the Flutter counter app, named `hookme`.
- [demo/](demo/README.md): build metadata and inject the native `puredart::core` payload.

The app package is `com.example.hookme`. The separate
[Hermes example](../../hermes/example/README.md) uses
`com.example.hermes.hookme`, allowing both apps on the same device.
